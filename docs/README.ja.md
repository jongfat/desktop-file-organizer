## 1.0.3 更新のお知らせ · 2026-10-05

Windows タスクトレイのアイコンを右クリック →「資料夾監視」（フォルダー監視）で、固定のデスクトップと追加の監視先を表示し、追加・変更・削除できます。設定は再起動後も保持されます。30秒ごとに全監視先を巡回し、それぞれの「桌面資料整理」に整理します。監視解除でデータは削除されません。オフラインやエラーがあっても他の場所は続行し、復帰後に再試行します。監視フォルダーとその上位フォルダーは元の場所に保持します。追加監視先の重複や包含はできません。

整理待ちファイルのローカル最終更新日が今日なら、形式を分けず「當日檔案(Today)」へまとめます。日付変更後の次の巡回で、前日以前のファイルを通常の分類へ移動します。当日に再更新したファイルは Today に残ります。ショートカットと元のサブフォルダー構造は保持し、既存の分類や元のサブフォルダー内から Today へ回収はしません。

一時停止と即時整理は全監視先に適用されます。単発のフォルダー整理も同じルールなので、日付変更後に再実行するか監視へ追加してください。**1.0.1／1.0.2 は OTA 更新可能、1.0.0 は 1.0.3 を手動インストールしてください。** [変更履歴](../CHANGELOG.md)

> **アイデアに場所を。散らかったファイルに居場所を。**

資料、スクリーンショット、インストーラー、圧縮ファイル。デスクトップを、ファイルの置きっぱなしにする場所から取り戻しましょう。

Desktop Organizer は Windows の通知領域に常駐し、単独のファイルを種類ごとに整理します。フォルダーは中身ごと移動。使い慣れたショートカットはそのまま残るので、作業を続けられます。

**サインイン時に起動 · 30 秒ごとに整理 · ショートカットを保持 · 同名でも上書きしない · インストーラーは 1 ファイル**

## 🚀 ひとつのファイルから、新しいデスクトップへ

プロジェクトのルートから見たインストーラーの場所：`bin/DesktopOrganizer-Setup-1.0.3.exe`。

**[⬇️ Windows インストーラーをダウンロード](https://github.com/jongfat/desktop-file-organizer/raw/refs/heads/main/bin/DesktopOrganizer-Setup-1.0.3.exe)**

1. EXE をダブルクリックし、繁体字中国語のセットアップに従います。
2. デスクトップのショートカット作成と、サインイン時の自動起動を選びます。
3. 最後の画面から起動するか、後でショートカットから起動します。

アプリ、警告アイコン、説明書、アンインストーラーを 1 個の EXE に同梱しています。このファイルを別の PC にコピーしてインストールできます。

**Windows 10／11** と **.NET Framework 4.8** が必要です。不足している場合はセットアップが案内します。現在のユーザー向けにインストールされ、既定の場所は `%LOCALAPPDATA%\Programs\DesktopOrganizer`。管理者権限は不要です。

**6 言語に対応しているのは README です。アプリ、セットアップ、実際のフォルダー名は現在も繁体字中国語です。以下の表は実際の名前を示しています。**

## 🗂️ ファイルごとに、決まった居場所

すべての分類はデスクトップの `桌面資料整理` に入ります。

| 形式 | 保存先 |
| --- | --- |
| DOC、DOCX | 文件 → Word |
| XLS、XLSX、CSV | 文件 → Excel |
| PPT、PPTX | 文件 → PowerPoint |
| PDF / TXT | 文件 → PDF / TXT |
| TIF、TIFF、PNG、JPG、JPEG、GIF、WEBP などの画像 | 圖檔（画像） |
| MP4、AVI、MOV、MKV、WEBM などの動画 | 影片（動画） |
| APK、EXE、MSI、MSIX、BAT、CMD、PS1 など | 程式（プログラム・スクリプト） |
| ZIP、RAR、7Z、TAR、GZ など | 壓縮檔（圧縮ファイル） |
| すでに中身をまとめたフォルダー | 資料夾 → 元のフォルダー名 |
| LEA など、その他の形式 | 其他類別 → 大文字の拡張子 |
| 拡張子なし | 其他類別 → 無副檔名 |

分類には拡張子を使い、本文の意味は解析しません。拡張子の大文字・小文字は区別せず、複数ある場合は最後の拡張子で判定します。`backup.tar.gz` は圧縮ファイルに入ります。分類フォルダーは必要なときだけ作成します。

## 🎛️ バックグラウンドで待機、操作はすぐに

デスクトップのショートカットをダブルクリックすると、ツールを起動して整理先を開きます。常駐済みならフォルダーだけを開きます。サインイン時の自動起動はバックグラウンドで動作します。

通知領域のアイコンを右クリックすると、今すぐ整理、一時停止、整理先を開く、履歴を見る、終了を選べます。アイコンのダブルクリックでもすぐに整理します。一時停止は今回の実行中のみ有効で、終了しても自動起動の設定は残ります。

## 🛡️ ファイルを守りながら、すっきり整理

- `.lnk`、`.url`、`.appref-ms` のショートカットはデスクトップに残します。
- 同名のファイルやフォルダーは `(1)`、`(2)` などを付けて保持し、上書きしません。
- 元のフォルダーは内部構造を保ったまま移動します。
- 過去 10 秒以内に更新された項目は後回しにします。移動の失敗は記録し、次の処理で再試行します。
- 隠し項目、システム項目、リンク、一部のダウンロード途中のファイル、Office の一時ファイルは対象外です。パブリック デスクトップも移動しません。
- 履歴は `%LOCALAPPDATA%\DesktopOrganizer\history.csv`。`MOVE` は移動の試行、`DONE` は完了、`ERROR` はエラーを表します。

Windows に設定されたユーザーのデスクトップを使用し、OneDrive にリダイレクトされたデスクトップにも対応します。自動起動のタイミングは Windows へのサインイン時です。

> ⚠️ **`桌面資料整理` には元のファイルが入っています。削除しないでください。** 警告アイコンは注意喚起であり、削除を禁止する機能ではありません。整理はバックアップではないため、重要なファイルは別途バックアップしてください。

## 🔄 更新・自動起動の停止・アンインストール

更新前に通知領域から終了し、新しいインストーラーを実行します。旧分類は現在の構成へ移行し、空になった旧分類を削除します。失敗した項目は保持して再試行します。

自動起動を停止するには、`Win + R` で `shell:startup` を開き、`桌面整理工具` のショートカットを削除します。現在常駐しているツールも終了してください。

アンインストールはツールを終了してから、Windows のインストール済みアプリまたはスタートメニューから実行します。アプリと作成したショートカットを削除し、**整理済みデータと履歴は残します**。手動でファイルをデスクトップに戻す前に、一時停止または終了してください。

## 🧰 ビルドとパッケージ作成

この GitHub 配布リポジトリにはインストーラーと説明書を掲載しています。以下のコマンドは、完全なローカル開発プロジェクトで使用します。

C#、Windows Forms、.NET Framework、Inno Setup 6 を使用しています。プロジェクトのルートで実行します。

```powershell
./build.ps1           # アプリとアイコンを生成
./test.ps1            # 分類・移動・移行をテスト
./build-installer.ps1 # bin に単一のインストーラー EXE を生成
./test-installer.ps1  # インストール・更新・削除・データ保持をテスト
```

既定のコンパイラーは `.tools/InnoSetup/ISCC.exe`。別の場所は `-CompilerPath` で指定できます。

開発用のインストールには `./install.ps1`、更新には `./install.ps1 -Update` を使用できます。既定の場所は `%LOCALAPPDATA%\DesktopOrganizer` で、更新時は既存のショートカットの場所を引き継ぎます。セットアップとは別のインストール方法です。

パッケージにはアプリ、設定、アイコン、説明書のみを含めます。`bin` は現在 Git の対象外です。配布する場合は生成した EXE を GitHub Releases にアップロードできます。
