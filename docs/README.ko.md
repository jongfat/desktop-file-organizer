## 1.0.12 · 2026-11-03

트레이 우클릭 메뉴의 **「結束」 바로 위에 「使用說明」(도움말)** 을 추가했습니다. 13개 기능을 각각 세 단계와 팁으로 안내합니다. **11개의 설명 그림과 인터페이스 축소 이미지를 클릭하여 확대할 수 있습니다.** 예제 데이터를 사용하며 모든 안내는 오프라인으로 제공됩니다. 시작 메뉴의 도움말도 같은 창을 엽니다.

## 1.0.11 · 2026-11-03

Today의 폴더 처리를 수정했습니다. 로컬 최종 수정일이 오늘이면 **파일, 폴더와 압축 파일 모두 「當日檔案(Today)」에 먼저 넣습니다**. 내부 구조를 유지하며 날짜가 바뀐 뒤 다음 검사에서 폴더 전체를 「資料夾」로 분류합니다. 업그레이드 첫 검사에서는 기록이 있고 오늘 수정되었으나 이전 버전에서 잘못 보관한 폴더도 수정합니다. 기록 없는 내용은 유지합니다.

이동 전 하위 파일까지 Windows 사용 상태를 확인합니다. 열림, 잠금, 갱신 중 또는 안전 여부를 확인할 수 없으면 원래 위치에 보관하고 다음 검사에서 다시 시도합니다. 다른 항목은 계속 처리하며 수동 정리에도 같은 보호를 적용합니다. 연기 수를 표시하고 `DEFER` 기록을 남깁니다. **읽은 뒤 핸들을 닫는 편집기의 열린 화면은 감지하지 못할 수 있습니다.** 기존 제외 규칙은 유지됩니다.

## 1.0.10 · 2026-10-30

트레이 메뉴에 **「重複檔名檢查」(중복 이름 검토)** 를 추가했습니다. 폴더와 하위 폴더 포함 여부를 선택하고 `aa.txt`, `aa(1).txt`, `aa (2).txt`를 그룹으로 봅니다. 다른 하위 폴더의 같은 이름도 후보이며 **내용이 같다는 뜻은 아닙니다**. 전체 경로를 확인하세요.

선택한 파일의 텍스트나 일반 이미지, 크기와 수정 시간을 미리 봅니다. UTF-8, UTF-16 BOM, Big5를 지원합니다. PDF와 Office 문서는 「以預設程式開啟」로 열어 비교합니다. 프로그램과 스크립트는 실행하지 않습니다.

처음에는 모두 보관하도록 체크됩니다. 불필요한 파일의 체크를 해제하고 **「保留勾選，回收其餘」** 를 눌러 확인합니다. 최소 한 파일을 보관하고 현재 그룹만 처리하며 이름은 바꾸지 않습니다. Windows 휴지통을 사용하고 실패 시 보존 및 알림 처리하며 영구 삭제로 전환하지 않습니다. 네트워크 및 이동식 드라이브는 수동으로 처리하세요.

창이 열린 동안 자동 정리를 멈추고 닫으면 원래 간격과 일시 중지 상태를 유지합니다. 변경되거나 사라진 파일은 다시 검사해야 합니다. 취소 가능하며 검사 한도는 100,000개, 텍스트는 65,536자, 이미지는 25 MB／4,000만 화소입니다. 지원하지 않는 이미지는 외부 앱으로 확인하세요.

## 1.0.9 · 2026-10-30

트레이 메뉴 → **「巡查時間」** → 숫자와 초／분／시간 단위를 선택해 저장합니다. 범위는 **30초～24시간**, 기본값은 **5분**이며 모든 감시 위치에 공통으로 적용됩니다. `%LOCALAPPDATA%\DesktopOrganizer\scan-settings.json`에 저장되어 재시작, 업그레이드와 제거 후에도 유지됩니다.

시작 직후 정리하지 않고 설정한 간격을 기다립니다. 정리 완료, 간격 저장 또는 자동 정리 재개 후 다시 시간을 셉니다. 수동 정리는 언제든 가능합니다. 간격 변경으로 일시 중지나 복원한 위치의 중지가 해제되지 않습니다.

## 1.0.7 · 2026-10-05: 원본 폴더 이름과 파일 복원

실제 원본 폴더 이름으로 결과를 만듭니다: `Download → Download檔案整理資料夾`. 이전 「桌面資料整理」 또는 「桌面整理工具」는 다음 정리에서 폴더 전체를 이전하며 내용, 분류와 기록의 경로 관계를 유지합니다.

트레이 오른쪽 클릭 → **「檔案回復」(파일 복원)** → 원본 폴더 선택 → 확인. 기록을 따라 원래 위치로 돌려놓습니다. Today 파일, 재분류된 파일과 원래 폴더 전체도 포함합니다. 바로가기는 유지됩니다. 같은 이름을 덮어쓰지 않으며 잠기거나 실패한 항목은 남겨 다시 시도할 수 있습니다. 기록 없는 내용은 유지합니다. 복원이 끝나고 사용자 내용이 남아 있지 않을 때만 결과 폴더와 도구가 생성한 경고 파일을 삭제합니다. 기록은 보존합니다.

## 1.0.5 · 2026-10-05: 드래그로 분류 변경

1.0.4의 규칙 트리에서 드래그할 수 없던 문제를 수정했습니다. .iso 같은 확장자를 「程式」에 놓으면 연결이 바뀝니다. 분류 전체를 옮길 때 「合併關聯」은 대상에 직접 병합하고, 「移為子分類」는 이름과 하위 구조를 유지합니다. 루트에 놓으면 최상위로 이동하고 확장자를 「其他類別」에 놓으면 자동 분류로 돌아갑니다. 대상 강조 및 트리 가장자리 스크롤을 지원합니다.

드래그는 초안만 바꿉니다. 「儲存並重新歸類」를 누르고 확인해야 저장 및 재분류합니다. 공통 규칙을 상속하는 위치는 전용 규칙을 활성화해야 편집할 수 있습니다. 고정 항목과 자신·하위 항목·확장자 대상 이동은 금지하며, 같은 이름의 하위 분류는 명시적으로 병합해야 합니다.

트레이 아이콘 우클릭 → **“規則”**에서 분류와 확장자 연결을 트리로 보고 추가·수정·삭제할 수 있습니다. ISO를 프로그램으로 분류하려면 “其他類別 → ISO → .iso”를 선택하고 “修改”에서 대상 “程式”를 고른 뒤 “儲存並重新歸類”를 누르세요. `.iso → 程式`를 직접 추가해도 됩니다. 아래 표는 변경 가능한 기본 규칙입니다.

모든 위치는 기본적으로 공통 규칙을 사용합니다. 바탕 화면이나 감시 폴더를 선택하고 “此資料夾使用專屬規則”를 선택하면 공통 규칙을 바탕으로 독립 설정을 만듭니다. 이후 공통 규칙 변경의 영향을 받지 않습니다. 체크를 해제하고 저장하면 공통 규칙을 다시 상속합니다. 감시 목록 변경 후 “重新載入”으로 갱신하세요. 일회성 폴더 정리에도 같은 규칙이 적용됩니다.

저장 전에 적용 위치를 확인한 후, 이동 기록이 있고 분류 폴더에 남아 있는 파일을 즉시 재분류합니다. “資料夾” 안의 원래 폴더와 기록 없는 파일은 그대로 둡니다. 오늘 파일은 Today에 남고 날짜가 바뀌면 최신 규칙을 사용합니다. 같은 이름을 덮어쓰지 않으며 잠긴 파일이나 오프라인 위치는 나중에 재시도합니다. 비워진 이전 분류 폴더만 제거합니다. 규칙 삭제는 파일을 삭제하지 않으며 연결 없는 형식은 “其他類別”의 대문자 확장자 분류로 돌아갑니다. Today와 바로가기·임시 파일 제외 규칙은 고정입니다. `%LOCALAPPDATA%\DesktopOrganizer\sorting-rules.json` 설정은 재시작·업데이트·제거 후에도 유지됩니다. 손상된 설정은 복구할 때까지 파일 이동을 중지합니다. [변경 이력](../CHANGELOG.md)

Windows 트레이 아이콘을 오른쪽 클릭 →「資料夾監視」(폴더 감시)에서 고정된 바탕화면과 추가 폴더를 확인하고 추가·수정·제거할 수 있습니다. 설정은 재시작 후에도 유지됩니다. 설정한 간격마다 모든 위치를 확인하며 결과는 각 폴더의 「XXX檔案整理資料夾」에 저장합니다. 제거는 감시만 중단하고 데이터를 삭제하지 않습니다. 오프라인이나 오류가 발생해도 다른 위치는 계속 처리하며 복구 후 재시도합니다. 감시 폴더와 상위 폴더는 원래 위치를 유지합니다. 추가 위치는 중복되거나 서로 포함할 수 없습니다.

정리 대기 파일의 로컬 최종 수정 날짜가 오늘이면 형식 구분 없이 「當日檔案(Today)」에 모읍니다. 날짜가 바뀐 뒤 다음 확인에서 이전 날짜 파일을 기존 유형별 폴더로 이동합니다. 오늘 다시 수정한 파일은 Today에 유지됩니다. 바로가기와 기존 하위 폴더 구조는 유지하며, 이미 분류된 폴더와 기존 하위 폴더 안의 파일을 Today로 다시 가져오지 않습니다.

일시 중지와 즉시 정리는 모든 위치에 적용됩니다. 단일 폴더 정리도 같은 Today 규칙을 사용하므로 날짜 변경 후 다시 실행하거나 감시 목록에 추가하세요. **1.0.1–1.0.11는 OTA로 업데이트할 수 있으며 1.0.0은 1.0.12을 수동 설치해야 합니다.** [버전 기록](../CHANGELOG.md)

> **아이디어를 위한 공간. 파일을 위한 제자리.**

보고서, 스크린샷, 설치 파일, 압축 파일. 바탕 화면을 파일이 쌓이는 공간에서 다시 작업을 시작하는 공간으로 바꿔 보세요.

Desktop Organizer는 Windows 시스템 트레이에서 대기하며 낱개 파일을 형식별로 정리합니다. 이미 정리해 둔 폴더는 내용과 함께 통째로 옮깁니다. 자주 쓰는 바로 가기는 그대로 남아 작업 흐름을 이어 갈 수 있습니다.

**로그인 시 시작 · 설정한 간격마다 정리 · 바로 가기 유지 · 같은 이름도 덮어쓰지 않음 · 설치 파일 하나**

## 🚀 설치 파일 하나로 새롭게 시작

프로젝트 루트 기준 설치 파일 위치: `bin/DesktopOrganizer-Setup-1.0.12.exe`.

**[⬇️ Windows 설치 파일 다운로드](https://github.com/jongfat/desktop-file-organizer/raw/refs/heads/main/bin/DesktopOrganizer-Setup-1.0.12.exe)**

1. EXE를 두 번 클릭하고 중국어 번체 설치 마법사의 안내를 따릅니다.
2. 바탕 화면 바로 가기와 로그인 시 자동 시작 여부를 선택합니다.
3. 마지막 화면에서 실행하거나 나중에 바로 가기로 실행합니다.

프로그램, 경고 아이콘, 사용 설명서, 제거 기능이 하나의 EXE에 포함됩니다. 다른 PC로 이 파일만 복사하면 설치할 수 있습니다.

**Windows 10/11** 및 **.NET Framework 4.8**이 필요합니다. 프레임워크가 없으면 설치 마법사가 안내합니다. 현재 사용자 계정에 설치하며 기본 위치는 `%LOCALAPPDATA%\Programs\DesktopOrganizer`입니다. 관리자 권한은 필요하지 않습니다.

**6개 언어는 README에만 적용됩니다. 프로그램과 설치 마법사, 실제 폴더 이름은 현재 중국어 번체입니다. 아래 표는 실제 폴더 이름을 사용합니다.**

## 🗂️ 파일마다 알맞은 자리

모든 분류는 바탕 화면의 `XXX檔案整理資料夾` 폴더 안에 생성됩니다.

| 형식 | 저장 위치 |
| --- | --- |
| DOC, DOCX | 文件 → Word |
| XLS, XLSX, CSV | 文件 → Excel |
| PPT, PPTX | 文件 → PowerPoint |
| PDF / TXT | 文件 → PDF / TXT |
| TIF, TIFF, PNG, JPG, JPEG, GIF, WEBP 등의 이미지 | 圖檔 — 이미지 |
| MP4, AVI, MOV, MKV, WEBM 등의 동영상 | 影片 — 동영상 |
| APK, EXE, MSI, MSIX, BAT, CMD, PS1 등의 프로그램과 스크립트 | 程式 — 프로그램 |
| ZIP, RAR, 7Z, TAR, GZ 등의 압축 파일 | 壓縮檔 — 압축 파일 |
| 내용이 들어 있는 기존 폴더 | 資料夾 → 원래 폴더 이름 |
| LEA 등의 기타 형식 | 其他類別 → 대문자 확장자 |
| 확장자 없음 | 其他類別 → 無副檔名 |

문서 내용을 분석하지 않고 확장자로 분류합니다. 확장자의 대소문자는 구분하지 않으며, 여러 확장자가 있으면 마지막 것을 사용합니다. `backup.tar.gz`도 압축 파일로 분류됩니다. 필요한 분류 폴더만 생성합니다.

## 🎛️ 백그라운드에서 대기, 필요할 때 바로 실행

바탕 화면 바로 가기를 두 번 클릭하면 도구가 시작되고 정리 폴더가 열립니다. 이미 실행 중이면 폴더만 바로 엽니다. 로그인 시 자동 시작은 백그라운드에서 이루어집니다.

트레이 아이콘을 오른쪽 클릭하면 즉시 정리, 자동 정리 일시 중지, 정리 폴더 열기, 기록 보기, 종료를 선택할 수 있습니다. 아이콘을 두 번 클릭해도 즉시 정리합니다. 일시 중지는 현재 실행에만 적용되며, 종료해도 로그인 자동 시작 설정은 유지됩니다.

## 🛡️ 파일은 그대로, 바탕 화면은 깔끔하게

- `.lnk`, `.url`, `.appref-ms` 바로 가기는 바탕 화면에 남습니다.
- 같은 이름에는 `(1)`, `(2)` 등을 붙여 기존 파일이나 폴더를 덮어쓰지 않습니다.
- 기존 폴더는 내부 구조를 유지한 채 통째로 이동합니다.
- 최근 10초 이내에 수정된 항목은 나중에 처리합니다. 이동 실패는 기록하고 이후 정리에서 다시 시도합니다.
- 숨김, 시스템, 링크 항목, 일반적인 다운로드 임시 파일과 Office 임시 파일은 건너뜁니다. 공용 바탕 화면도 이동하지 않습니다.
- 기록 위치는 `%LOCALAPPDATA%\DesktopOrganizer\history.csv`입니다. `MOVE`는 시도, `DONE`은 완료, `ERROR`는 오류입니다.

Windows에 설정된 사용자 바탕 화면 경로를 사용하며 OneDrive로 리디렉션된 바탕 화면도 지원합니다. 자동 시작은 Windows 로그인 시 이루어집니다.

> ⚠️ **`XXX檔案整理資料夾`에는 원본 파일이 들어 있습니다. 삭제하지 마세요.** 경고 아이콘은 안내일 뿐 삭제를 차단하지 않습니다. 정리는 백업이 아니므로 중요한 파일은 별도로 백업하세요.

## 🔄 업데이트, 자동 시작 해제, 제거

업데이트 전 트레이에서 종료한 뒤 새 설치 파일을 실행합니다. 기존 분류를 현재 규칙에 맞게 옮기고 비워진 이전 분류 폴더는 삭제합니다. 실패한 항목은 유지하고 다시 시도합니다.

자동 시작을 해제하려면 `Win + R`로 `shell:startup`을 열고 `桌面整理工具` 바로 가기를 삭제합니다. 현재 실행 중인 도구도 종료하세요.

제거 전 도구를 종료한 뒤 Windows의 설치된 앱 또는 시작 메뉴에서 제거합니다. 프로그램과 설치 시 만든 바로 가기는 제거되지만 **정리된 데이터와 기록은 유지됩니다**. 파일을 바탕 화면으로 직접 옮기기 전에는 일시 중지하거나 종료하세요.

## 🧰 빌드 및 패키징

이 GitHub 배포 저장소에는 설치 파일과 설명서가 포함됩니다. 아래 명령은 전체 로컬 개발 프로젝트에서 사용합니다.

C#, Windows Forms, .NET Framework, Inno Setup 6을 사용합니다. 프로젝트 루트에서 실행하세요.

```powershell
./build.ps1           # 프로그램과 아이콘 생성
./test.ps1            # 분류, 이동, 마이그레이션 테스트
./build-installer.ps1 # bin에 단일 설치 EXE 생성
./test-installer.ps1  # 설치, 업데이트, 제거, 데이터 유지 테스트
```

기본 컴파일러는 `.tools/InnoSetup/ISCC.exe`입니다. 다른 경로는 `-CompilerPath`로 지정할 수 있습니다.

개발용 설치는 `./install.ps1`, 업데이트는 `./install.ps1 -Update`를 사용합니다. 기본 위치는 `%LOCALAPPDATA%\DesktopOrganizer`이며 업데이트 시 기존 바로 가기의 위치를 사용합니다. 설치 마법사와는 별도의 설치 방식입니다.

설치 파일에는 프로그램, 설정, 아이콘, 설명서만 포함합니다. 현재 `bin`은 Git에서 제외되어 있습니다. 배포하려면 생성한 EXE를 GitHub Releases에 업로드할 수 있습니다.
