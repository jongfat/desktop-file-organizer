## 1.0.5 · 2026-10-05：拖曳即可調整分類

修正 1.0.4 規則樹無法拖曳的問題。可將副檔名（如 .iso）拖到「程式」直接改變關聯；也可拖曳整個 ISO 分類，選擇「合併關聯」讓檔案直接歸到程式，或「移為子分類」保留為程式／ISO。子分類與副檔名一併更新，拖到整理根節點可移回頂層；副檔名拖到「其他類別」恢復自動歸類。目標會反白，拖到樹的上下邊緣可捲動。

拖曳先修改草稿，按「儲存並重新歸類」並確認才套用。取消或放棄未儲存變更不搬移檔案。繼承共用規則的來源需先勾選專屬規則才能編輯；Today、原資料夾與排除節點固定。禁止拖到自身、子孫或副檔名節點；同名子分類需明確合併。

系統匣圖示按右鍵 → **「規則」**，以樹狀畫面查看分類與副檔名關聯。可新增分類／副檔名、修改分類名稱與關聯、刪除規則。例如選取「其他類別 → ISO → .iso」，按「修改」，將目標改為「程式」，再按「儲存並重新歸類」。也可直接新增 `.iso → 程式`。以下分類表為預設，可依需求調整。

預設所有來源共用規則。選擇桌面或某個監視資料夾，勾選「此資料夾使用專屬規則」，即可從共用規則建立獨立設定；之後修改共用規則不影響它。取消勾選並儲存，恢復繼承共用規則。監視清單變更後，按「重新載入」更新選擇範圍。不同來源各自套用規則，單次「整理所選資料夾」也使用相同設定。

儲存前會列出受影響的來源並確認，確認後立即重新歸類**整理紀錄中曾搬移、目前仍在歸檔分類的檔案**。不掃描或拆開「資料夾」內的原始內容，不改動未記錄的檔案；Today 的今日檔案繼續保留，跨日後使用最新規則。同名不覆蓋；鎖定或離線保留重新歸類要求，下一輪重試。移空的舊分類只清除空資料夾。

刪除副檔名關聯或分類不會刪除檔案，相關格式回到「其他類別／大寫副檔名」。未關聯格式仍自動歸類；Today、原資料夾保留及捷徑／暫存排除為固定規則。規則存於 `%LOCALAPPDATA%\DesktopOrganizer\sorting-rules.json`，重啟、升級、解除安裝均保留；若設定損壞，停止搬移並提示修復，避免錯誤歸類。[完整版本紀錄](CHANGELOG.md)

在 Windows 系統匣程式圖示上按右鍵 →「資料夾監視」，即可查看固定監視的桌面及額外來源，並新增、修改、移除資料夾。清單儲存後重啟仍保留，每 30 秒一併巡查；移除只停止監視，不刪除資料。每個來源各自建立「桌面資料整理」。位置離線或整理失敗時，其他來源照常處理，恢復後重試。受監視資料夾與其上層資料夾保留原位置；重複或互相包含的額外來源不可加入。

**當天待整理的檔案，依本機「最後修改日期」先集中至「桌面資料整理／當日檔案(Today)」，不分格式。** 跨日後下一輪巡查再按原規則分到 Word、Excel、PDF、圖檔等分類。Today 裡當天又修改過的檔案繼續保留；原子資料夾仍整包移至「資料夾」，捷徑保留。已歸檔分類及原子資料夾內部檔案不會重新收回 Today。

「暫停自動整理」套用全部來源；「立即整理」巡查全部來源。原有「整理所選資料夾」仍可選擇、確認後整理一次，同樣套用 Today 規則，跨日後需再次整理或加入監視。

系統匣「版本 · 檢查更新」顯示版本、日期及更新內容。**1.0.1～1.0.5 可透過 OTA 升級；1.0.0 請手動安裝 1.0.6。** [後續版本發布流程](updates/README.md)

## 🚀 一個安裝檔，重新開場

成品位置：`bin/DesktopOrganizer-Setup-1.0.6.exe`。

**[⬇️ 下載 Windows 安裝程式](https://github.com/jongfat/desktop-file-organizer/raw/refs/heads/main/bin/DesktopOrganizer-Setup-1.0.6.exe)**

1. 雙擊 EXE，跟著繁體中文安裝精靈操作。
2. 選擇桌面捷徑與登入自動啟動。
3. 在最後一頁選擇立即啟動，或稍後從捷徑呼叫。

程式、警示圖示、使用說明與解除安裝功能，全都包在這一個 EXE。複製到另一台電腦，即可安裝。

適用 **Windows 10／11**，需要 **.NET Framework 4.8**；缺少時安裝精靈會提示。安裝於目前使用者帳號，預設位置為 `%LOCALAPPDATA%\Programs\DesktopOrganizer`，不需要管理員權限。

**六種語言提供的是 README；目前程式介面、安裝精靈及實際資料夾名稱維持繁體中文。**

## 🗂️ 每種檔案，都有自己的位置

```text
桌面資料整理
├─ 當日檔案(Today)
├─ 文件
│  ├─ Excel
│  ├─ PDF
│  ├─ PowerPoint
│  ├─ Word
│  └─ TXT
├─ 圖檔
├─ 影片
├─ 程式
├─ 壓縮檔
├─ 資料夾
│  └─ 原資料夾（保留內部結構）
└─ 其他類別
   ├─ LEA
   ├─ MP3
   └─ …其他副檔名
```

| 檔案格式 | 整理後的位置 |
| --- | --- |
| DOC、DOCX | 文件 → Word |
| XLS、XLSX、CSV | 文件 → Excel |
| PPT、PPTX | 文件 → PowerPoint |
| PDF / TXT | 文件 → PDF / TXT |
| TIF、TIFF、PNG、JPG、JPEG、GIF、WEBP 等圖片 | 圖檔 |
| MP4、AVI、MOV、MKV、WEBM 等影片 | 影片 |
| APK、EXE、MSI、MSIX、BAT、CMD、PS1 等程式與腳本 | 程式 |
| ZIP、RAR、7Z、TAR、GZ 等壓縮檔 | 壓縮檔 |
| 已經裝好內容的資料夾 | 資料夾 → 原資料夾名稱 |
| LEA 等其他格式 | 其他類別 → 大寫副檔名 |
| 沒有副檔名 | 其他類別 → 無副檔名 |

分類依副檔名，不讀取內文做語意判斷。大小寫視為同一格式；多重副檔名取最後一段，像 `backup.tar.gz` 也會歸入「壓縮檔」。有對應檔案時才建立分類，不堆出一排空資料夾。

## 🎛️ 背景待命，隨時接手

雙擊桌面捷徑會啟動工具並開啟「桌面資料整理」；已常駐時直接開啟資料夾。登入自動啟動則保持背景執行。

右鍵點選系統匣圖示，可**立即整理、暫停自動整理、開啟整理資料夾、查看整理紀錄或結束**。雙擊系統匣圖示也能立即整理。暫停只適用本次執行；結束程式不會取消登入啟動設定。

## 🛡️ 整齊，也要保留你的資料

- **捷徑留在原位：** `.lnk`、`.url`、`.appref-ms` 保留在桌面。
- **同名都留下：** 撞名時加上 `(1)`、`(2)` 等編號，不覆蓋。
- **資料夾整包搬：** 保留內部結構，不拆開專案內容。
- **還在更新的，稍後處理：** 最近 10 秒有更新的項目延後；搬移失敗會記錄並在後續輪次重試。
- **系統項目略過：** 隱藏、系統、連結項目、常見下載暫存檔及 Office 暫存檔不整理；公共桌面也不搬移。
- **每次搬移有跡可查：** 紀錄位於 `%LOCALAPPDATA%\DesktopOrganizer\history.csv`。`MOVE` 是嘗試，`DONE` 是完成，`ERROR` 是錯誤。

使用 Windows 設定的目前使用者桌面路徑，支援已重新導向至 OneDrive 的桌面。自動啟動發生在**登入 Windows 時**。

> ⚠️ **「桌面資料整理」保存原始資料，請勿刪除。** 警示圖示不會鎖住刪除權限。整理不等於備份，請另行備份重要檔案。

## 🔄 更新、停用與解除安裝

**更新：** 先從系統匣結束工具，再執行新版安裝程式。舊分類會按目前規則調整；清空後移除舊分類，失敗項目保留並重試。

**停止登入自動啟動：** 按 `Win + R` 輸入 `shell:startup`，刪除「桌面整理工具」捷徑，再從系統匣結束目前常駐。

**解除安裝：** 先結束工具，再從 Windows 的已安裝應用程式或開始功能表解除安裝。程式及安裝建立的捷徑移除，**整理資料與紀錄保留**。手動把資料搬回桌面前，請先暫停或結束工具。

## 🧰 開發與打包

GitHub 發佈儲存庫提供安裝檔與說明文件；以下命令適用完整的本機開發專案。

採用 C#、Windows Forms 與 .NET Framework；安裝包使用 Inno Setup 6。在專案根目錄執行：

```powershell
./build.ps1           # 編譯程式與產生圖示
./test.ps1            # 驗證分類、搬移及升級
./build-installer.ps1 # 產生單一 EXE 到 bin
./test-installer.ps1  # 驗證安裝、更新、解除安裝與資料保留
```

編譯器預設為 `.tools/InnoSetup/ISCC.exe`，也可指定其他位置：

```powershell
./build-installer.ps1 -CompilerPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

開發安裝可用 `./install.ps1`，更新可用 `./install.ps1 -Update`。此途徑預設安裝於 `%LOCALAPPDATA%\DesktopOrganizer`，更新會沿用現有捷徑位置；它與完整安裝精靈是不同途徑。

安裝包只包含指定的程式、設定、圖示與說明。建置輸出 `bin` 目前由 Git 忽略；要在 GitHub 提供下載，可將產生的單一 EXE 上傳至 Releases。
